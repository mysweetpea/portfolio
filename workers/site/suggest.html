Before you suggest

A few things we look for in every suggestion.

Check if the service is open source and can be self-hosted. We prioritize privacy-focused, community-driven projects.
  • Open source — the code should be publicly available and self-hostable.
  • Privacy-focused — we favor services that respect user data and avoid tracking.
  • Community value — the more members it helps, the better.
  • Uniqueness — we only add services we don't already provide.

We review every suggestion and add the best ones to the garden.
