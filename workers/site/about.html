About MySweetPea

Self-hosted services for a privacy-first community.

Our Mission

I care deeply about privacy. In today's world, your personal data is the product. Companies track what you do, what you watch, who you talk to, and what you search for. I wanted to change that. MySweetPea is my way of giving you private, secure alternatives to the services you use every day — without the tracking, the ads, or the corporate data mining.

I also genuinely enjoy doing this. Building and maintaining this project is something I genuinely enjoy. Every service running here is one less reason to depend on a big tech company that does not have your best interests at heart.

Why Self-Hosting?

I host everything locally on my own hardware. I do not rent cloud servers from Amazon, Google, or Microsoft. The only external service is a small relay server that helps people access the media streaming from outside my home network.

This means:

  • Full control over the infrastructure and your data
  • No third-party access to your data — not even mine, since services like the password manager use encryption that even I cannot break
  • No vendor lock-in — if I shut down tomorrow, you still have your data
  • Transparency — all infrastructure code is public on GitHub for anyone to inspect

The Cost of Running MySweetPea

Running these services is not free, which is why donations matter. Here are the main expenses:

  • Electricity — three servers running 24 hours a day, 7 days a week use a lot of power
  • Hardware — the physical servers, networking equipment, and storage drives that need occasional upgrades
  • Internet bandwidth — streaming movies and serving services to multiple users at once requires a fast, reliable connection
  • Domain registration — the mysweetpea.cc web address needs to be renewed every year
  • Relay server — a small server that helps people outside my home network access the media streaming

Donations help cover these ongoing costs and fund future improvements and new services. Without community support, this project would not be sustainable. Every dollar helps keep MySweetPea running.

Open Source

Every service we run is open source, meaning the code is freely available for anyone to inspect. Our infrastructure code is public on GitHub, so you can see exactly how everything is set up and secured. No black boxes, no hidden tracking, full transparency.
