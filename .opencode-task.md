# TASK: Aurora Mobile 8 — stop iOS "reverts to desktop view" after a while (SPA-only; single file)

USER REPORT: On iPhone Safari the dashboard starts with the correct mobile layout, but after
some time it "reverts to desktop view" — content appears zoomed-out/wide and must be reloaded
to look right again.

ROOT CAUSE (classic iOS behavior, confirmed in code): iOS Safari **auto-zooms the page when an
input with font-size < 16px receives focus** and the zoom persists after the keyboard closes —
the page then looks like a desktop page shrunk onto the phone until reloaded. This dashboard has
3 offending form rules:
- `.mcard input` → font-size .95rem (15.2px)
- `.sgf input,.sgf select,.sgf textarea` → font-size:.92rem (14.72px)
- `.pwf input` → font-size:.92rem (14.72px)
Plus the palette input `#pal-q` and any other inputs inheriting body size.

FIX (CSS-only + one meta attribute):
1. Viewport meta: change to
   `<meta name="viewport" content="width=device-width,initial-scale=1,maximum-scale=1">`
   (prevents iOS focus auto-zoom; pinch-zoom accessibility is preserved by iOS ignoring
   maximum-scale for manual pinch since iOS 10 — this only blocks the automatic zoom).
2. At the end of the stylesheet add ONE labeled block:
```
/* ---- aurora mobile 8: iOS focus auto-zoom guard ---- */
@media (max-width:760px){
  input, select, textarea { font-size: 16px !important; }
}
```
   (16px is the iOS threshold — with it, focusing any input never triggers the zoom.
   !important is required to beat the .92/.95rem rules above.)
