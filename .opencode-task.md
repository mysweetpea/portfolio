## FIX 1 — Ghost band between "Keep watching" and "Your account" (STILL broken on iPhone)

`hmUnCard()` builds `.hm-card.hm-un` cards whose children are ALL absolutely positioned
(`.hm-wide-art` inset:0, `.hm-wide-meta` bottom:12, `.hm-un-type` top:10 right:10) — the card's
only height source is `aspect-ratio:16/9` + width, which iOS Safari 15/16 sometimes fails to
apply inside grid tracks when combined with `width:100%!important` (the mobile-7/9 cascade).
The result on the user's iPhone: 0-height cards, titles stacked in a garbled band.

ROBUST FIX (do it in JS + CSS):
- In `hmUnCard()`: add an explicit inline `style="aspect-ratio:16/9"` on the `<a>` AND wrap the
  two text lines in a static-flow footer instead of relying only on absolute positioning:
  keep `.hm-wide-meta` absolutely positioned BUT add `<span class="hm-un-pad"></span>` spacer —
  NO, simpler and bulletproof: give `.hm-un` a `min-height` fallback in CSS:
  `@media (max-width:760px){ .hm-rail>.hm-un{min-height:99px} }` AND add a static-flow meta
  variant: change `hmUnCard` to emit the meta OUTSIDE absolute positioning on mobile via a
  `.hm-un-meta-static` span (title + why), hidden on desktop (`display:none` above 760px),
  shown on mobile (`display:block;padding:8px 2px 0`), while `.hm-wide-meta` stays for desktop.
  Cards then ALWAYS have intrinsic height from normal flow on iOS.
- Keep everything else (link, badge, art) unchanged.
