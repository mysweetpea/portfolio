# TASK: Aurora Mobile — fix horizontal overflow + mobile polish (SPA-only; single file)

The dashboard at `workers/dashboard/public/index.html` has **horizontal scroll on mobile**
(the page moves sideways). Fix the root causes and polish the mobile experience.

## Step 1 — Diagnose BEFORE editing

Use grep to list every CSS rule that can exceed viewport width on small screens. Known
suspects in this file (verify each, find others):
- `body::before` ambience uses `inset:-20%` with a fixed-position element (can create
  overflow if not clipped)
- Rails/orbs/grids with fixed min-widths (`.sv-grid` minmax 150px, `.sv-orbs`, `hm-*` rails)
- `.sv-spot` fixed-width radial gradient child (420px circle)
- Any `width:` or `min-width:` over ~340px, negative margins, `white-space:nowrap` outside
  intentional rails
- The `.top-nav` at small widths (many buttons: site-back + search + account + 8 tabs)

## Step 2 — The fixes

1. **Root overflow kill**: `html,body{overflow-x:hidden}` (html AND body) + ensure no
   `width:100vw` anywhere (100vw includes scrollbar -> overflow; use 100%).
2. **Ambience**: `body::before` must never create scroll — add
   `contain:strict`-equivalent approach: keep `position:fixed` + add `overflow:hidden` via
   clip-path, or simplest: `body{position:relative}` + `body::before{position:absolute;
   inset:0;overflow:hidden}` with an inner oversized gradient via a pseudo of the pseudo
   is NOT possible — instead keep fixed but add `pointer-events:none` (already) and
   `clip-path:inset(0)` or wrap the oversized gradient in `background-size` terms that fit.
   Pick the cleanest solution that provably kills overflow.
3. **Rails**: horizontal scroll INSIDE rails is correct (keep `overflow-x:auto` +
   `scroll-snap` + `-webkit-overflow-scrolling:touch` + hidden scrollbars via
   `scrollbar-width:none`/`::-webkit-scrollbar{display:none}`). Page-level scroll must die;
   rail-level scroll is the pattern.
4. **Nav on mobile (<=760px)**: verify the current breakpoint rules. The 8 tabs +
   site-back + search + account must fit: if they don't, make the tab row horizontally
   scrollable within the nav (`overflow-x:auto`, no wrap, masked fade edge) — nav row
   scrolls, page doesn't. Never let the nav push the page wide.
5. **Spotlight/banner/hero/ledger** (sv-spot, hm-hero, st2-hero, abanner if present):
   stack vertically <=760px, full-width, no fixed heights that exceed small phones.
6. **Media/stats grids**: minmax down to fit 320px viewports (e.g. minmax(140px,1fr));
   ensure `min-width:0` on grid/flex children that contain long words; add
   `overflow-wrap:anywhere` on titles/blurbs.
7. **Typography**: hero numbers and spotlight names must scale down via clamp()
   (verify existing clamps; add where missing).
8. Do NOT change any logic/JS behavior. CSS + minimal markup classes only.
